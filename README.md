## 💎 Key Features

* **Liquid Neon Design:** A "Titanium Flow" aesthetic with mathematical parallax backgrounds.
* **Kinetic Typography:** Text decoding effects and smooth scroll reveals.
* **Dynamic Project Showcase:** Detailed case studies for **QGen AI** and **Hostel OS**.
* **Bubble Physics:** Interactive cards that respond to mouse movement with spring physics.
* **Performance Optimized:** Sub-second load times using Vite and React best practices.
* **Integrated Contact System:** Serverless form handling with instant browser alerts.

## ⚡ Installation & Local Setup

Want to run this locally? Follow these steps:

1.  **Clone the Repo**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/aditya-portfolio-2026.git](https://github.com/YOUR_USERNAME/aditya-portfolio-2026.git)
    cd aditya-portfolio-2026
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Start Development Server**
    ```bash
    npm run dev
    ```

4.  **Build for Production**
    ```bash
    npm run build
    ```
